# PhysGround data

This directory contains **versioned experiment inputs**, not generated benchmark results.

## reference/pushbench_v1.json

The canonical 19-case definition for `PhysGround-PushBench-v1`.

Each case records:

- initial planar object pose;
- goal pose and tolerances;
- simulation-only ground-truth latent physics;
- the prior physics hypotheses available to the algorithm;
- optional model-mismatch terms used only by P5.

The benchmark loader reads this file directly. This prevents the experimental
case matrix from being hidden inside Python control flow.

## What was migrated from FitGround

**No garment-specific observations, images, pattern measurements, cloth meshes,
or garment labels are reused as robot-pushing data.** They describe a different
physical system and would create invalid evidence.

What is intentionally carried over is the *experimental discipline*:

- interventions are versioned;
- simulator truth and model belief are separated;
- observed outcomes are stored rather than inferred from intended actions;
- unsupported/model-mismatch cases can abstain;
- result artifacts are generated from reproducible experiment inputs.

## Generated data

Episode traces, posterior beliefs, predictions, and benchmark result artifacts
are generated by PhysGround itself and should be written under `artifacts/`
or another run directory. They are not committed by default.

Future MuJoCo and SO-101 datasets must use the same case/episode identity and
record observed before/action/after transitions plus calibration/provenance.
